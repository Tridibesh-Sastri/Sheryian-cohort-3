## Core Content 
- addEventListner(-,-,-)
    Slot 1 (type): The string name of the event (e.g., 'click').
    Slot 2 (listener): The callback function that runs when the event happens.
    Slot 3 (options OR useCapture): This single slot accepts one of two types:
        useCapture: A Boolean (true/false): This is the old way. It only controls capturing.
        Options: An Object ({ }): This is the modern way. It allows you to configure multiple settings at once (like capture, once, passive, and signal).
